### 2026-10-12 晚（绝学3 实测反馈第二轮：密度带虚拟格线）

**用户再测**：绝学3（白文小字刻本）547~556 页仍全部「可分析页不足」。

**直接诊断用户书库真实页面**（`GujiBT/1791308271178/page_546..555.png`）：
- 逐页 1118 个连通域**全数 <200px**（最大 184，字宽 ~14px 小字 + Otsu 断笔）
- 投影 maxCol=287 < 检测阈 297——**无界栏格线**
- 逐页异文——字形块跨页本就匹配不上

三重夹击下字块与界栏特征双双为零。投影法能对齐这类页靠的是**文字
列/行的密度结构**——把它引入特征框架：

**密度带虚拟格线**（[feature_points.dart] `_densityLines`）：
- 页面分 3 段，每段投影峰（平滑 5 + 高度阈 + 间距 ≥15px）就近链接
  成链（≥2 段），链即"虚拟格线"，与真界栏同构走交点/插值机制
- **拟合直接由链上段峰回归**（关键修复：`_fitLines` 的 ±3px 带窗是
  为 1-2px 界栏设计的，25px+ 宽的密度带在偏转下整带漂移十几像素，
  带窗截掉斜率信号导致系统性欠旋转 ~25%）
- 双向各 ≥3 条带才启用（稀疏页不误触发）
- 合成生成器同步修正：笔画居中写在格内（真实刻本形态；随机散布
  会让带心晃 ±5px）

**绝学3 真实十页验证（用户路径完整复现）**：
- **10/10 全部对齐**，101ms，角度 0~0.64°，平移 ≤30px，内点率 38-68%
- 对照：投影法同批页 7/10 对齐且有 −112px 整列错位（回声峰病灶）
- 5 张 periods 样本复验无回归；29 个对齐单测全绿；全量 570 通过

**已知边界**：偏转 >1.2°（真实扫描的 ~3 倍）时密度带在投影上互相
糊并、共识角偏低——单测按 1.2° 压力档锁定。

### 2026-10-12 下午（真实数据适配第一轮，periods 样本驱动）

**用户实测**：10 页全部「可分析页不足」——合成数据没有覆盖真实古籍形态。

**用 test_images/periods 的 5 张真实样本逐层诊断，发现三个真实性问题并修复**：

1. **界栏格网吞字**（宋元刻本 98% 连通域异常）：格线把整列字织成
   13k+ 像素巨型连通域 → 投影带式线检测（带宽 ≤12px 区分线与文字
   列，对 ±1° 偏转稳健）+ 整带清除 + 长 run 清除。
2. **逐页文字不同，字形块跨页匹配不上**（合成测试全是同字页，真实
   相邻页文字不同！）：版式格线才是跨页稳定特征 → **交叉点特征**
   （v线×h线交点，描述子=纸面归一化位置，分类型匹配不与字形块互
   配）。这是把 Phase 2 的界栏交叉点计划提前实现为核心特征。
3. **投影塌缩熨平旋转**（交叉点网格在旋转页上仍是正交网格）：线分
   段峰位置回归拟合（抛物线亚像素峰抗字形污染）→ 交叉点用插值求
   真交点（自带旋转几何，±3px 塌缩误差 → 亚像素）。
4. 闭运算默认关闭（稠密刻本列距 3-5px，r=1 会把整页焊成大块，
   实测 44→0 特征）。
