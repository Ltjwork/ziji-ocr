# 字迹插件开发指南

字迹支持 **Obsidian 式的外挂插件**：插件是一个独立的压缩包文件
（`.zjplugin`，本质是 zip），运行时导入安装，不需要重新编译软件。
插件用 HTML/JavaScript 编写界面与逻辑，通过软件提供的 `ziji.*` 桥 API
读写书库、调用后端、访问网络。

- 安装位置：应用数据目录 `plugins/<插件id>/`（升级 = 重新导入新包，插件
  自己保存的数据不丢）。
- 开发热重载：改完插件把新文件直接覆盖进上述安装目录，到「设置 → 插件」
  点该插件的**重新加载**即取最新版（新 `main.js` 运行时重启、已开的插件
  页面自动关闭），无需重启应用、也无需重新导入 `.zjplugin`。
- 运行方式：每个启用插件有一个**常驻后台运行时**（跑 `main.js`），
  打开功能入口时再创建**页面窗口**（加载插件的 HTML 页面）。
- 界面技术：WebView2（Edge 内核）。页面里可以用常规 HTML/CSS/JS。

## 插件包结构

```
manifest.json      ← 必需：插件清单（见下）
main.js            ← 必需：后台主脚本（注册入口、后台任务）
review.html        ← 可选：页面（入口/设置页打开的 HTML）
settings.html      ← 可选：设置页（manifest.settings 指向它）
其他资源            ← 可选：css/js/图片，页面内用相对路径引用
```

打包：把以上文件压成 zip，改扩展名为 `.zjplugin` 即可（zip 根层直接
放文件，或包一层顶层目录都行，安装时会自动剥掉）。

## manifest.json 字段

```json
{
  "id": "my_plugin",            // 必需。小写字母开头，只含小写字母/数字/下划线，2~31 字符
  "name": "我的插件",            // 必需。显示名
  "version": "1.0.0",           // 必需。插件版本（展示与升级提示用）
  "description": "一句话说明",    // 建议。插件列表里显示
  "author": "你",                // 可选
  "api_version": 1,             // 必需。当前为 1；不一致会拒绝安装
  "min_app_version": "1.0.2",   // 可选。低于该版本拒绝安装
  "entry": "main.js",           // 必需。后台主脚本路径
  "settings": "settings.html",  // 可选。设置页路径（有则插件卡出现齿轮）
  "icon": "cloud_sync",         // 可选。图标名（见文末白名单）
  "permissions": ["storage"]    // 必需声明（可空数组）。用到的权限都要申请
}
```

## 权限

插件能做什么由 manifest 里申请的权限决定。未申请权限的命令会被拒绝
（调用报错），安装卡片上也会向用户展示权限清单。

| 权限 | 说明 | 覆盖的命令 |
|---|---|---|
| `http` | 自由访问网络（经宿主代理，免 CORS） | `http.request`、`http.uploadFile` |
| `storage` | 插件私有存储（全局 + 按书） | `storage.*` |
| `projects:read` | 读书库与页标注 | `projects.list/readAnnotation/annotationMtimes/charUids` |
| `projects:write` | 写回页标注（宿主口径收口） | `projects.applyCharConfirmations` |
| `backend` | 调用本地后端接口 | `backend.get/post` |
| `export` | 构建识字任务包 | `export.charPackage` |

## 桥 API（`window.ziji`）

页面与 main.js 里都有全局 `ziji` 对象：

```js
const result = await ziji.invoke('命令', 参数);   // 全部命令走这一个入口
ziji.on('事件名', (payload) => { ... });          // 收宿主/其他会话转发的事件
```

调用失败会 **reject**（`Error`，`message` 为中文错误说明）。

### 应用与状态

| 命令 | 参数 | 返回/说明 |
|---|---|---|
| `app.info` | — | `{appVersion, apiVersion, pluginId, booksRoot}` |
| `app.setStatus` | `{text}` | 状态行文本（识别监控悬浮窗「插件」区展示；空文本撤下） |
| `app.log` | `{text, isError?}` | 写应用日志（后端控制台可见） |
| `app.emit` | `{event, payload?}` | 向本插件的 main.js 运行时转发事件（页面 → 运行时） |

### 存储（需 `storage` 权限）

两级存储，值可为任意 JSON。全局存储升级插件时保留。

| 命令 | 参数 | 说明 |
|---|---|---|
| `storage.get` / `storage.set` / `storage.remove` | `{key[, value]}` | 全局（本插件私有） |
| `storage.projectGet` / `storage.projectSet` / `storage.projectRemove` | `{projectDir, key[, value]}` | 按书（落在 `{书目录}/plugin_data/<插件id>.json`，随书走） |

### 网络（需 `http` 权限）

宿主代理请求，不受浏览器 CORS 限制。

```js
// 普通请求
const r = await ziji.invoke('http.request', {
  method: 'POST',
  url: 'https://example.com/api',
  headers: { 'Authorization': 'Bearer ...' },  // 可选
  body: '任意文本（JSON.stringify 后的字符串）',   // 可选
  timeoutMs: 30000,                              // 可选，默认 60 秒
});
// r = { status: 200, headers: {...}, body: '...' }

// 上传宿主导出的任务包（只能传 export.charPackage 返回的文件）
const r2 = await ziji.invoke('http.uploadFile', {
  url: 'https://example.com/upload',
  fields: { name: '批次名' },      // multipart 表单字段，可选
  headers: { 'X-Auth': '...' },   // 可选
  filePath: exported.filePath,    // 能力路径
  timeoutMs: 600000,              // 可选，默认 10 分钟
});
```

### 本地后端（需 `backend` 权限）

调用字迹本地 Python 后端的 JSON 接口（如字块缩略图）：

```js
const r = await ziji.invoke('backend.post', {
  path: '/char_thumbnails',
  body: { items: [{ image_path, x, y, w, h }], size: 64 },
});
// r 即后端响应的 JSON 对象，例如 { thumbs: [base64, ...] }
```

### 书库与标注（需 `projects:read`）

| 命令 | 参数 | 返回 |
|---|---|---|
| `projects.list` | — | `[{dir, name, pageCount, lastPageIndex, importPending}]` |
| `projects.readAnnotation` | `{projectDir, pageId}` | 页标注**紧凑投影**（无标注为 null）：`{pageId, imagePath, reviewed, draftSaved, boxesReviewed, mainRegionCount, lines: [{id, text, orientation, chars: [{id, x, y, w, h, order, type, status, confirmed, boxConfirmed, text}]}]}` |
| `projects.annotationMtimes` | `{projectDir}` | `{pageId: 毫秒时间戳}`（标注文件修改时间——增量同步的断点依据） |
| `projects.charUids` | `{projectDir, pageId, chars: [{x,y,w,h,order}]}` | 与输入同序的稳定 uid 数组（识字任务包口径：源图 sha256 + 几何 + 行内正文字序） |

页号约定：`page_007` 形式（0 基第 7 页）。`order` 必须传「行内正文字
（type == main_text）列表中的下标」，与导出器口径一致。

### 写回标注（需 `projects:write`）

**唯一**的标注写入口（插件不能直接改标注文件）：

```js
const r = await ziji.invoke('projects.applyCharConfirmations', {
  projectDir, pageId,
  chars: [{ id: '字块id', text: '新文字' }, ...],
});
// r = { appliedIds: [...], unmatchedIds: [...] }
```

宿主按字块 id 定位、更新文字并**确认**（与编辑器「确认并保存」同口径：
confirmCharsById 级联、行文本重拼、训练统计入账），逐页落盘。

### 识字任务包（需 `export` 权限）

```js
const exported = await ziji.invoke('export.charPackage', {
  projectDir, pageIds: ['page_001'], onlyCharUids: ['uid-...'],
});
// exported = { filePath, taskCount }
// 用完（上传完/放弃）记得释放：
await ziji.invoke('fs.release', { path: exported.filePath });
```

`onlyCharUids` 用 `projects.charUids` 计算。包体是 zip（含字图），经
`http.uploadFile` 上传。

### 界面（无需权限）

| 命令 | 限 | 说明 |
|---|---|---|
| `ui.registerEntries` | main.js | 声明功能入口（出现在编辑器「全书操作」菜单）：`{entries: [{id, title, subtitle?, icon?, page, requiresProject?}]}`。`requiresProject: true` 表示无书时不出现 |
| `ui.openPage` | 任意 | 打开一个插件页面：`{page, title?}` |
| `ui.closePage` | 页面 | 关闭当前页面并携带回执：`{result: {modifiedPages: [0基页序]}}`——编辑器按回执刷新受影响页 |
| `ui.getContext` | 页面 | 页面打开上下文：`{projectDir?, projectName?, pageIndex, entryId?}` |

## 完整示例：最小插件

`manifest.json`：

```json
{
  "id": "page_counter",
  "name": "页数速览",
  "version": "1.0.0",
  "description": "在入口页显示书库每本书的页数。",
  "api_version": 1,
  "entry": "main.js",
  "icon": "menu_book",
  "permissions": ["projects:read"]
}
```

`main.js`：

```js
await ziji.invoke('ui.registerEntries', {
  entries: [{
    id: 'main', title: '页数速览', icon: 'menu_book',
    page: 'page.html', requiresProject: false,
  }],
});
```

`page.html`：

```html
<!doctype html><meta charset="utf-8">
<ul id="list"></ul>
<script>
(async () => {
  const projects = await ziji.invoke('projects.list');
  document.getElementById('list').innerHTML = projects
    .map((p) => `<li>《${p.name}》 ${p.pageCount} 页</li>`)
    .join('');
})();
</script>
```

## 调试

- 插件页面里 `console.log` 不可见；用 `app.log` 输出到应用日志（后端
  控制台窗口或日志文件可查）。
- 桥调用报错会 reject，`catch (e) { await ziji.invoke('app.log', {text: String(e), isError: true}); }`。
- 升级插件后若行为未变：重新导入过包（安装卡片会提示「已升级」），或
  直接覆盖了安装目录文件但忘了在「设置 → 插件」点**重新加载**——已打开
  的插件页面在重载时会自动关闭，重新打开的才是新代码。

## 安全模型

插件在本机全权运行（与 Obsidian 同级信任）：权限清单在安装时展示，
但插件 JS 一旦运行即可请求其申请的全部能力。**只从可信来源安装插件**。
