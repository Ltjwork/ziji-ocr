## 逐张出处

### 01 先秦 · 郭店楚简《老子》甲组
- 1993 年湖北荆门郭店一号楚墓出土，战国中期（约前 4 世纪中—前 3 世纪初），现存最早的《老子》抄本。
- 收藏：荆门市博物馆；发掘：湖北省文物考古研究院。
- 图片来源：湖北省文物考古研究院官网发布照片（经图片索引入库）；直链为镜像缓存：
  `https://image-search-mcp-cn-beijing.oss-cn-beijing.aliyuncs.com/image-search-mcp/images-ppt/82b23002e4aa.jpeg`
- 742×3110px，4 支简，双道编绳，无水印。原站为动态列表页，permalink 未能锁定，内容已经两轮视觉模型核验（楚文字、形制与郭店《老子》甲组一致）。

### 02 汉魏 · 马王堆帛书《老子》乙本
- 1973 年长沙马王堆三号汉墓出土（墓封于文帝十二年，前 168 年）；乙本避高祖刘邦讳（"邦"改作"国"）、不避惠帝/文帝讳，学界一般断为高祖至惠帝年间（约前 200–前 188）抄本，书风为规整八分隶；甲本不避邦讳、抄写更早。注：制作基准时经逐列辨读更正——初判甲本有误，甲本《德经》开篇顶部残损、首见字应为"德"，而本图版首列自顶部起清晰完整，与乙本相符（详见 gt/02_hanwei.json 的 gt_notes）。
- 收藏：湖南博物院。图版出自官方图录《马王堆汉墓帛书[壹]》（文物出版社，1980）扫描件。
- 来源页（含全书扫描）：https://archive.org/details/mawangdui
  本图取自该扫描本的《老子》乙本图版（首列自顶可辨读"上德不德，是以有德…"）。
- 3068×4171px，300dpi。

### 03 南北朝 · 北魏写经《摩诃衍经》卷廿五
- 传敦煌出土，东京国立博物馆藏，列品号 TB-1430；馆藏定年"北魏时代·5–6 世纪"（南北朝北朝）。
- 来源页（官方藏品库 ColBase）：https://colbase.nich.go.jp/collection_item/115019
  直接图片：`https://colbase.nich.go.jp/media/tnm/TB-1430/image/main/TB-1430_E0127580.jpg`
- 3000×1411px，乌丝栏、行约 17 字，纸本墨书卷子。
- 备注：首选候选知恩院藏西魏大统十六年（550）《菩萨处胎经》官方图源最高仅 900px，不满足分辨率，故改选此卷（同为北朝、机构断代权威）。

### 04 宋元 · 南宋黄善夫刻《史记》
- 南宋庆元年间（约 1195–1200）建安黄善夫家塾刊《史记集解索隐正义》三家注合刻本，存卷二、卷三；狩谷棭斋求古楼旧藏，现藏东京大学东洋文化研究所（B1112000）。国图藏六十九卷残本与此同出一部。
- 来源页：Commons 文件页 `IOC.UTokyo-002265 史記殘二卷慶元中建安黃善夫刊本`（内嵌东洋文化研究所汉籍数据库直链 http://kanseki.ioc.u-tokyo.ac.jp/user/query_detail_im.php?nu=B1112000 ）
- 本图由该机构扫描 PDF 第 25 页按 3.2× 渲染提取，为一个完整对页；2907×2304px；粗黑口、双鱼尾、大字正文小字双行注，少量朱批在行间不碍正文。

### 05 明清 · 《永乐大典》嘉靖副本
- 明嘉靖年间（约 1562–1567）重录副本，卷 10110–10112 册中一叶（f.34v）；都柏林 Chester Beatty Library 藏，馆号 C 1757。
- 来源页（图书馆官方数字馆藏）：https://viewer.cbl.ie/viewer/image/C_1757/70/
  下载经 Wikimedia Commons：`File:Page from the 'Great encyclopaedia of the Yongle Reign' (Yongle dadian) (CBL C 1751, f.34v).jpg`（文件名中 C 1751 为上传者笔误，馆藏编目为 C 1757）
- 4582×8151px，朱丝栏、朱笔句读、台阁体楷书，公有领域，无水印。

## OCR 测试要点
- 书体跨越：战国楚文字（异体最多）→ 古隶 → 隶楷写经体 → 宋刻楷体（印刷）→ 明台阁体（写本）。
- 版式跨越：竹简（竖条）→ 帛书（无界栏）→ 卷子（乌丝栏）→ 蝴蝶装对页（版心/鱼尾/大小字）→ 包背装（朱丝栏）。
- 04 含朱笔批校，可顺带测试颜色分离；02 为织物底纹，可测试背景噪声。
